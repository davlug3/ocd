## What is on the board
Same 46 parts as the 1590B design:
- **Core circuit:** R1–R15, C1–C11, D1, D_PWR, D_LED, R_LED, M1, M2
- **U1 (DIP-8):** one TL082 package
- **X2 / X4 / X5:** Drive, Tone and Volume pots
- **J_IN / J_OUT:** PCB-mounted 1/4" jacks
- **J_PWR:** 9 V DC jack, center-negative, switched
- **BT1:** 2-pin header for 9 V battery snap
- **SW_FS:** 2×05 header for 3PDT true-bypass switch
- **SW_HP:** 1×03 header for HP/LP toggle
